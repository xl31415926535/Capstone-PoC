# SIMCC Science Studio v2

已完成可运行的出题与审核原型：**大纲目标 → 推理任务设计 → 批量出题 → 隐藏答案盲解 → 教师审核与纠正 → 获批题库 → 学生练习**。这是一套使用现有模型的应用引擎，没有训练或交付新的基础模型权重。当前范围是 P5 Standard Electrical System 的闭合电路、导体与绝缘体。

## 启动与演示

需要 Node.js 20+，没有第三方依赖，无需 npm install。在本目录的 PowerShell 执行：

```powershell
./start-local.ps1
```

教师工作台：http://127.0.0.1:4317 ，学生练习：http://127.0.0.1:4317/practice 。保持终端打开，Ctrl+C 停止。也可以运行 `node server.mjs`；启动脚本会尝试发现本机官方 Codex CLI。指定其他端口可用 `./start-local.ps1 -Port 4320`。

**没有 API 预算也能展示完整流程：**

```powershell
node scripts/start-recorded-demo.mjs
```

打开 http://127.0.0.1:4319 。它加载 17 道此前真实生成的草稿及两轮历史报告，界面标明 Recorded run，在线调用全部禁用。每次启动创建独立演示数据目录，操作不会修改正式本机题库。数据保存在终端显示的 `runtime/recorded-demos/demo-*` 目录；下次启动会重新加载未审批副本。历史结果不代表本次实时生成。演示审核请使用明确的测试身份和意见。

## 建议展示顺序

1. **Evaluation**：选择最新一轮，展示 10 道题、5 种推理任务、所有尝试和盲解提醒。第一轮失败也保留，不能只展示成功题。
2. 点开一道题，在 **Evidence & review** 查看任务设计、MOE 对应目标、规则检查、盲解结果和模型原创性说明。
3. 使用 **Academic labels & corrections** 修改难度、技能或学习目标，并填写审核人和理由。系统保存修改前后标签、增加版本号、撤销旧审批及模型评审；v2 新版本须重新盲解后才可审批。无在线调用的记录演示中，此步骤只能展示撤销审批，无法重新盲解。
4. 由实际审核者判断科学性、大纲、原创性和适龄性，记录通过、退回或拒绝，以及可选的问题类别和主动审核分钟数。**模型同意不能代替教师审批。**
5. 获批当前版本进入 **Approved bank**；学生页按目标、难度、技能筛选，从题库抽题。提交前不返回答案；提交后显示得分、简明解题步骤、各干扰项解释和建议复习目标。学生流程不调用模型。
6. 无获批题时，可点学生页的 **Try unreviewed demo**。它始终标注未审核演示，不进入正式题库和人工通过率。
7. 导出批次评估、审核反馈、获批题库或单题 Review sheet。打印页可通过浏览器“打印 → 另存为 PDF”保存。

## 生成引擎 v2

五种任务：材料性质推断、电路结果预测、故障诊断、实验选择、科学论断评价。一次选择 1、5 或 10 题，以及混合或指定的暂定难度。生成器从目标与推理任务设计新题，已有题目仅作避免重复的参照；不会把更换人名或选项顺序当作原创能力的证据。

每批使用两次模型调用：生成结构化草稿；再仅传学生题面与课程目标，隐藏答案、解释和设计说明进行盲解。输出包含四个选项、唯一拟定答案、学生可读的简明步骤、干扰项解释、目标映射、难度与设计标签。这里的步骤是教学解释，不是模型隐藏推理过程。

本地检查执行 JSON 结构、选项、答案引用、解释覆盖、表格、大纲来源和本机语句重合检查。开放题型不套用旧版固定电路的布尔证明；显示 Not run 并要求完成盲解。盲解缺失或答案分歧会阻止审批；其他提醒仍需教师判断。编辑后的过期异步结果不会附到新版本。

## 实际运行证据

2026-09-29 使用现有官方 Codex 登录运行两批。第二批 10/10 存储成功、10/10 本地结构规则通过、10/10 盲解答案一致；其中 7 题仍有年龄适用性、理想化假设或措辞提醒。**这不是科学准确率 100%，所有题仍待人工审核。** 第一批保留 3 次结构拒绝及 1 道盲解无法确定唯一答案的题。

- `examples/evaluation-v2.json`：第二批全部结果、使用量和指标定义。
- `examples/evaluation-v2-first-run.json`：第一批失败记录。
- `examples/questions-v2.json`：两轮共 17 道实际存储的草稿及审核证据。
- `examples/live-v2-review.html`：可离线打开的 v2 单题审核单。
- `examples/live-run.json`、`live-review.html`：此前 v1 真实运行记录。

CLI 未回传实际模型名称，记录保持 null，不声称是某个 GPT 版本。独立调用使用同一服务，不是跨厂商验证。人工通过率和审核时间在真实填写前均为空。难度没有学生作答数据校准；本地相似度不证明全网或 SIMCC 题库原创性。

## 配置在线模型

密钥只设置在服务器终端环境，页面不接收密钥；修改后重启服务器。Configured 只表示检测到配置，不验证余额和连接。本程序不自动读取 .env。

- **Codex CLI**：使用本机官方 CLI 登录；`codex login status` 查看状态，`codex login` 登录。可设置 `SIMCC_CODEX_BIN` 和可选 `SIMCC_CODEX_MODEL`。使用现有 Codex 配额，推理在线完成。[官方非交互模式文档](https://learn.chatgpt.com/docs/non-interactive-mode)。
- **Gemini**：`GEMINI_API_KEY` 和 `GEMINI_MODEL`。
- **OpenAI API**：`OPENAI_API_KEY` 和 `OPENAI_MODEL`，独立 API 计费。
- **Jev**：`TYPESAFE_API_KEY`、可选 `JEV_MODEL`；仅作可选文本评审，不能自动审批。

后三种适配器尚未配置真实项目密钥或完成服务联调。主界面支持另选提供商对单题重新盲解，但只有实际执行后才能称为跨服务验证。不购买 API 不影响已保存证据演示。每次模型调用超时为 6 分钟，每批最多两次；一次只运行一个任务。请求失败如实显示，不静默替换为录制样题。

## 数据、测试与边界

`data/records.json` 保存题目和追加式审核事件；`data/evaluations/records.json` 保存批次。可用 `SIMCC_DATA_DIR` 指定数据目录。备份时停止服务后复制整个数据目录。服务中断的未完成批次在重启时标为 interrupted，不自动重试。Codex 输入、输出、回执位于 `runtime/jobs/`，不作为静态页面公开。

学生会话一小时后失效，答案仅在服务器内存中；重启会结束会话。若题目被改版或撤回，已打开的练习提交会被拒绝，须重新开始。审核反馈导出供之后分析使用，不自动转成获准训练数据。

运行 `node --test test/*.test.mjs`：目前 **36 项离线测试通过**，不消耗模型额度。验证细节见 [VALIDATION.md](VALIDATION.md)。v2 的 HTTP 与接口验证完成，但浏览器工具无法核验本机站点访问权限，**本次尚未完成新版页面的视觉及点击复测**。

该原型只监听本机，无本地 GPU 依赖；教师与学生页面的分离不等于生产环境的角色权限隔离。尚未实现全学段大纲、授权试卷 OCR、LearnDash 导入、学生实测校准、模型微调、多人认证或公开部署。源码包不含本机运行数据、调试目录和账号凭据，只含明确标注的合成题示例及历史结果。
