# SIMCC Science Studio v2

已完成可运行的出题与审核原型：**大纲目标 → 推理任务设计 → 批量出题 → 本地检查（大纲范围、电路求解、与源题比对） → 隐藏答案盲解 → 教师审核与纠正 → 获批题库 → 学生练习 → 用作答校准难度**。这是一套使用现有模型的应用引擎，没有训练或交付新的基础模型权重。

**当前范围**：出题限于 P5 Standard Electrical System 第 59 页中适合选择题考查的 5 条学习成果（电路是一个系统、闭合电路、导体与绝缘体、电路图、串并联电池与灯泡）。2023 小学科学大纲全文（P3–P6 共 18 个主题、22 条“不要求”说明）已录入，用于给源题打标签和筛查超纲内容。

[Source bank 说明](docs/BANK.md) · [试点方案](docs/PILOT.md) · [验证记录](VALIDATION.md) · [接口约定](CONTRACT.md)

## 启动与演示

建议 Node.js 24（已测试）；源题库需要 Node.js 22.5 以上（内置 node:sqlite）。没有第三方依赖，无需 npm install。在本目录的 PowerShell 执行：

```powershell
./start-local.ps1
```

教师工作台：http://127.0.0.1:4317 ，学生练习：http://127.0.0.1:4317/practice 。保持终端打开，Ctrl+C 停止。也可以运行 `node server.mjs`；启动脚本会尝试发现本机官方 Codex CLI。指定其他端口可用 `./start-local.ps1 -Port 4320`。

**没有 API 预算也能展示完整流程：**

```powershell
node scripts/start-recorded-demo.mjs
```

打开 http://127.0.0.1:4319 。它加载 17 道此前真实生成的草稿及两轮历史报告，界面标明 Recorded run，在线调用全部禁用；同时建一个示例源题库（项目组自编的 9 道题，不是真实试卷）。每次启动创建独立演示数据目录，操作不会修改正式本机题库。数据保存在终端显示的 `runtime/recorded-demos/demo-*` 目录；下次启动会重新加载未审批副本。历史结果不代表本次实时生成。演示审核请使用明确的测试身份和意见。

## 建议展示顺序

1. **Evaluation**：选择最新一轮，展示 10 道题、5 种推理任务、所有尝试、盲解提醒和与源题的重合度。第一轮失败也保留，不能只展示成功题。
2. 点开一道题，在 **Evidence & review** 查看任务设计、MOE 对应目标、超纲筛查、规则检查、盲解结果和模型原创性说明。
3. 在 Studio 选 Recorded example 中的电路题：服务器画出电路图并求解；故意写错答案的版本会被求解器拦下。
4. **Source bank**：检索源题、查看配图、确认或否决大纲标签；**Syllabus coverage**：按主题和学习成果统计源题与生成题。
5. 使用 **Academic labels & corrections** 修改难度、技能或学习目标，并填写审核人和理由。系统保存修改前后标签、增加版本号、撤销旧审批及模型评审；v2 新版本须重新盲解后才可审批。无在线调用的记录演示中，此步骤只能展示撤销审批，无法重新盲解。
6. 由实际审核者判断科学性、大纲、原创性和适龄性，记录通过、退回或拒绝，以及可选的问题类别和主动审核分钟数。**模型同意不能代替教师审批。**
7. 获批当前版本进入 **Approved bank**；学生页按目标、难度、技能筛选，从题库抽题。提交前不返回答案；提交后显示得分、简明解题步骤、各干扰项解释和建议复习目标。学生流程不调用模型。学生对获批题的作答进入 Evaluation 页的 **Pupil responses and difficulty**。
8. 无获批题时，可点学生页的 **Try unreviewed demo**。它始终标注未审核演示，不进入正式题库、人工通过率或作答统计。
9. 导出批次评估、审核反馈、匿名作答、获批题库或单题 Review sheet。打印页可通过浏览器“打印 → 另存为 PDF”保存。

## 生成引擎 v2

五种任务：材料性质推断、电路结果预测、故障诊断、实验选择、科学论断评价。一次选择 1、5 或 10 题，以及混合或指定的暂定难度。生成器从目标与推理任务设计新题，已有题目仅作避免重复的参照；不会把更换人名或选项顺序当作原创能力的证据。

每批使用两次模型调用：生成结构化草稿；再仅传学生题面与课程目标，隐藏答案、解释和设计说明进行盲解。盲解可以选用与生成不同的提供商，独立性更强。输出包含四个选项、唯一拟定答案、学生可读的简明步骤、干扰项解释、目标映射、难度与设计标签。这里的步骤是教学解释，不是模型隐藏推理过程。

本地检查执行 JSON 结构、选项、答案引用、解释覆盖、表格、大纲来源、超纲用语和本机语句重合检查。

- **电路图**：题目带电路图时，服务器按相同的理想电池和灯泡求解；答案与求解结果不符、两个或没有选项符合、选项标签对不上或电池短路，都会拦下。学生和盲解都看不到间隙中物体的材料。
- **与源题比对**：有源题库时，每道草稿与库中用词最接近的 25 道题及生成时参考的题比对。标签（A、S1）和数字先遮蔽，换名字或换数字的抄题照样能查出。重合 60% 以上拦下，35% 以上提醒。文字比对查不出换了说法的同一想法，原创性仍需教师确认。
- **检索试点**：勾选 “Show the generator matching source questions” 后，提示词附上最多 6 道 P5 电学源题，只用来参考难度、考法和常见误解，明令不得照搬。Evaluation 页按带与不带汇总对比；`scripts/retrieval-pilot.mjs` 可成对运行，或先 `--dry-run` 不调用模型看会附上哪些题。见 [docs/PILOT.md](docs/PILOT.md)。

开放题型没有电路图时不套用固定电路的布尔证明；显示 Not run 并要求完成盲解。盲解缺失或答案分歧会阻止审批；其他提醒仍需教师判断。编辑后的过期异步结果不会附到新版本。

## 源题库

`scripts/import-bank.mjs` 用 Utkarsh 的 olympiad 数据库和/或项目组整理的 JSON 建库，表结构与他的一致，他的练习查询可直接运行；另外存大纲标签、配图、质量标记和审核记录，重建时保留审核决定。真实试卷和建好的库文件不进 Git（`data/` 已忽略）。2026-10-07 的私有库：42 份文件、299 题，其中 12 题标为 P5 电学，4 题可作检索参考；ACS 第 18 题的电路由求解器独立得出与官方答案相同的结果。详见 [docs/BANK.md](docs/BANK.md)。

## 学生作答与难度校准

学生提交获批题时，服务器只记下题目编号与版本、所选选项和是否答对，不存姓名、账号或设备信息；演示题不记录，重复提交不重复计数。同一版本满 20 份作答后显示难度档：答对率 80% 以上为 Easy，50% 以上为 Medium，以下为 Hard，并附 95% 区间。难度档与标签不符、干扰项比正确答案更多人选、某干扰项几乎没人选，都会提示教师。改标签会产生新版本，重新计数。

## 实际运行证据

2026-09-29 使用现有官方 Codex 登录运行两批（早于大纲、电路和源题库的工作）。第二批 10/10 存储成功、10/10 本地结构规则通过、10/10 盲解答案一致；其中 7 题仍有年龄适用性、理想化假设或措辞提醒。**这不是科学准确率 100%，所有题仍待人工审核。** 第一批保留 3 次结构拒绝及 1 道盲解无法确定唯一答案的题。

- `examples/evaluation-v2.json`：第二批全部结果、使用量和指标定义。
- `examples/evaluation-v2-first-run.json`：第一批失败记录。
- `examples/questions-v2.json`：两轮共 17 道实际存储的草稿及审核证据。
- `examples/live-v2-review.html`：可离线打开的 v2 单题审核单。
- `examples/live-run.json`、`live-review.html`：此前 v1 真实运行记录。

CLI 未回传实际模型名称，记录保持 null，不声称是某个 GPT 版本。人工通过率和审核时间在真实填写前均为空。尚无学生作答数据；尚未有带检索或换提供商盲解的真实运行。本地相似度和源题比对不证明全网或 SIMCC 题库原创性。

## 配置在线模型

密钥只设置在服务器终端环境，页面不接收密钥；修改后重启服务器。Configured 只表示检测到配置，不验证余额和连接。本程序不自动读取 .env。

- **Codex CLI**：使用本机官方 CLI 登录；`codex login status` 查看状态，`codex login` 登录。可设置 `SIMCC_CODEX_BIN` 和可选 `SIMCC_CODEX_MODEL`。使用现有 Codex 配额，推理在线完成。[官方非交互模式文档](https://learn.chatgpt.com/docs/non-interactive-mode)。
- **Gemini**：`GEMINI_API_KEY` 和 `GEMINI_MODEL`。
- **OpenAI API**：`OPENAI_API_KEY` 和 `OPENAI_MODEL`，独立 API 计费。
- **Jev**：`TYPESAFE_API_KEY`、可选 `JEV_MODEL`；仅作可选文本评审，不能自动审批。

后三种适配器尚未配置真实项目密钥或完成服务联调。只有实际用另一家提供商盲解后才能称为跨服务验证。不购买 API 不影响已保存证据演示。每次模型调用超时为 6 分钟，每批最多两次；一次只运行一个任务。请求失败如实显示，不静默替换为录制样题。

## 数据、测试与边界

`data/records.json` 保存题目和追加式审核事件；`data/evaluations/` 保存批次；`data/responses/` 保存匿名作答；`data/question-bank.sqlite` 是源题库（可用 `SIMCC_BANK_DB` 指定）。可用 `SIMCC_DATA_DIR` 指定数据目录。备份时停止服务后复制整个数据目录。服务中断的未完成批次在重启时标为 interrupted，不自动重试。Codex 输入、输出、回执位于 `runtime/jobs/`，试点报告位于 `runtime/`，均不作为静态页面公开。

学生会话一小时后失效，进行中的会话只在服务器内存中；重启会结束会话。若题目被改版或撤回，已打开的练习提交会被拒绝，须重新开始。审核反馈导出供之后分析使用，不自动转成获准训练数据。

运行 `node --test test/*.test.mjs`：本机 **77 项离线测试通过**（Node.js 22.22），不消耗模型额度；GitHub Actions 在 Linux 和 Windows 上用 Node.js 24 运行。验证细节见 [VALIDATION.md](VALIDATION.md)。页面已用无界面 Chromium 脚本点击并截图检查（Studio、Evidence、Evaluation、Source bank、Syllabus coverage、学生页），无控制台错误；这不等于教师或学生的可用性测试。

该原型只监听本机，无本地 GPU 依赖；教师与学生页面的分离不等于生产环境的角色权限隔离。尚未实现授权试卷 OCR、LearnDash 导入、模型微调、多人认证或公开部署；出题仍只限 P5 电学。源码包不含本机运行数据、调试目录和账号凭据，只含明确标注的合成题示例及历史结果。
