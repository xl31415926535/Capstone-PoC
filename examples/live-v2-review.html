A link for a lamp

Primary 5 / Standard / Electrical System · MCQ · Difficulty Easy (provisional)

Student question

A small lamp has a reliable low-voltage battery, a working bulb and secure wires. An uncoated link made entirely of material Z joins the only gap. The link touches both wire ends securely and is the only connection across the gap. The bulb lights.

All information is supplied in the text and data table. No external diagram is required.

What does this observation show about material Z?

  1. Z allows electric current to pass through it.
  2. Z prevents electric current from passing through it.
  3. Z supplies all the electricity needed by the bulb.
  4. Z must be attracted to a magnet.

Answer and distractors

Option 1. The lit bulb shows that Z provides a conducting connection that completes the circuit.

  • Option 2: A material that prevents current from passing would leave this circuit incomplete.
  • Option 3: The battery supplies electrical energy. The link provides a connection.
  • Option 4: This test gives evidence about electrical conduction, not attraction to magnets.

Student-facing solution steps

  1. The only path across the gap passes through Z.
  2. The bulb lights, so current can pass through Z.
